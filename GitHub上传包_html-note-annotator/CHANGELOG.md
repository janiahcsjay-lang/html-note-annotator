# 更新日志

## v2.0.0 · 2026-09-09
- 划词标注：选中一段文字即可对具体字句留标注，文字高亮
- 框选标注：拖矩形标注箭头、间距、留白等"没有元素可点"的位置
- 标注分类：类型（文案/视觉/交互/疑问）× 轻重（必改/建议），钉子按类型着色、必改带红圈，面板可按类型筛选
- 带图报告：逐条滚动截图，生成按类型分组、必改在前的图文 HTML 报告
- 防丢与总览：未导出的内容修改关页提醒；「总览」页列出所有标注过的文件；支持从其他文件导入标注（文件改名迁移）
- 清单升级：按类型分组、必改在前，划词条目带原文

## v1.1.0 · 2026-09-08
- 流程图（SVG）支持标注到单个节点（g 分组），不再只能选整图
- 交互式页面：钉子跟随交互状态——切屏收起、返回自动回归（MutationObserver + 容器滚动跟踪）
- 高亮改为覆盖框，不再改动页面 class

## v1.0.0 · 2026-09-08
- 元素级标注：点哪标哪，查看/定位/完成/删除
- 一键隐藏/显示标注；页面内容直接编辑（Ctrl/⌘+Z 撤销）
- 标注清单：页内弹窗，一键复制或下载 .md（含给 AI 的改稿说明）
- 导出自包含 HTML：标注嵌进文件，接收方无需插件即可查看
- 标注按网址保存在本机浏览器（chrome.storage / localStorage 双轨）
