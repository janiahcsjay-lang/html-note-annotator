# HTML 标注笔记 · Chrome 插件（v2.0）

在任何页面上做标注：点选元素、划词圈字、拖框选区域；分类型分轻重；一键隐藏；可编辑页面内容；可导出带标注的 HTML、文字清单和带截图的图文报告。标注保存在你自己的浏览器里，按网址记忆。

## 安装（约 1 分钟）

1. 解压这个压缩包，得到文件夹「HTML标注笔记-插件」（放到一个不会误删的位置，安装后不能删）。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 右上角打开「开发者模式」。
4. 点「加载已解压的扩展程序」，选刚才解压的文件夹。已装过旧版的话，点旧版卡片上的刷新按钮即可。

**要标注本地 HTML 文件的话（重要）**：在 `chrome://extensions` 里点开本插件的「详情」，打开「**允许访问文件网址**」。

## 使用

打开任何页面，点一下插件图标，右上角出现工具条：

- **标注**：点元素落钉子；**划选一段文字**松手即可对那几个字留标注（文字会高亮）。流程图（SVG）里可以标到单个节点。
- **框选**：按住拖一个矩形，标注"没有元素可点"的位置——箭头、间距、留白。
- 写标注时可选**类型**（文案／视觉／交互／疑问，钉子按类型着色）和**轻重**（必改的钉子带红圈）。面板顶部可按类型筛选。
- **隐藏标注**：一键隐藏/显示所有钉子和高亮。
- **编辑内容**：整页文字直接可改（Ctrl/⌘+Z 撤销）。有未导出的修改时，关闭页面会提醒。
- **清单**：全部标注按类型分组、必改在前，复制全文粘给 AI，或下载 .md；**带图报告**会逐条滚动截图，生成一份图文对照的 HTML 报告（发群里或留档都直观）。
- **导出 HTML**：另存一份带标注的完整文件——发给别人打开也能看到钉子和高亮，对方不需要装插件。
- **总览**：列出所有标注过的文件（条数、未完成、最后更新），可打开、导出清单、删除记录。

## 说明

- 交互式页面（点着点着会切屏的原型）：钉子和高亮跟着交互状态走——切走时收起，回到对应画面自动回来；清单里会注明哪些标注不在当前画面。
- 交互原型里「编辑内容」改的文案可能被页面脚本重画覆盖——这类页面的文案真源在代码里，建议标注后导出清单交给 AI 直接改源文件。
- 文件改名或移动后标注按网址对不上：打开新文件 → 点「标注」→ 空状态下点「从其他文件导入标注」即可迁移（原记录保留）。
- 「带图报告」每条截图间隔约一秒（浏览器截图频率限制），条数多时稍等即可。
- 插件不联网、不上传任何数据，所有内容只存在你的电脑里。
